# Mobile Patterns (Global)

## Navigation
- Mobile primary navigation should converge to bottom navigation for top user journeys.
- Drawer should host secondary navigation and account actions.

## Layout
- Single-column sections with clear vertical rhythm.
- Use tokenized gutters and safe-area spacing.
- Avoid desktop multi-column compression; use section-based reflow.

## Components
- Touch targets should keep comfortable hit-area (>=44px).
- Card/list/settings row paddings and radii should remain consistent.
- Form actions should preserve clear primary vs secondary hierarchy.

## P0 pages
- Overview: KPI-first, supporting details below.
- My/Profile: grouped settings rows.
- Billing: action-focused list and summaries.
- Support: concise ticket list + clear detail CTA.
